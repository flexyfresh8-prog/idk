Run this bot in your browser — no Python install required

Discord's API blocks direct browser access (CORS), so a self-bot must run somewhere with a real server. Click either button below — it deploys the bot to a free cloud host that gives you a working dashboard URL you can open in any browser. No local Python, no command line.

Deploy to Render (free, 1-click) Open in GitHub Codespaces (free, browser-based)

Render: easiest — sign in with GitHub, click Apply, set 3 secret env vars in their UI, deploy. Free tier spins down after 15 min idle (kills bot). For 24/7 upgrade to $7/mo.
Codespaces: gives you a real terminal in the browser (60 free hours/month). Run pip install -r requirements.txt && python app.py, port 5000 auto-forwards.

What this page is (and isn't)

This is a static configuration form. It runs entirely in your browser — nothing is sent to any server. Your settings are saved in localStorage on this device only.

It is NOT a live bot dashboard. Use it to generate a .env file you can paste into Render's UI (recommended), or download and use with the local/Codespaces setup.

Self-bots violate Discord's ToS — use a burner account. See the README.

Deployment

The bot itself can't run on GitHub Pages (no Python runtime). Pick one of these options to actually run the bot — then visit your bot's URL to use the live dashboard.

Option 1: Fly.io (recommended — free always-on)
  1. Install flyctl: instructions here
  2. Clone the repo: git clone https://github.com/flexyfresh8-prog/idk.git & cd idk
  3. Launch & set secrets & deploy:
fly launch --no-deploy
fly secrets set DISCORD_USER_TOKEN=<your-token>
fly secrets set AI_API_KEY=<your-key>
fly secrets set TARGET_USER_ID=<your-target-id>
fly deploy

Fly will give you a URL like https://discord-ai-selfbot.fly.dev — that's your live dashboard.

Option 2: Render (easier UI, but free tier sleeps after 15 min idle)
  1. Sign up at render.com
  2. New → Web Service → connect your GitHub account → select flexyfresh8-prog/idk
  3. Render auto-detects render.yaml → click Apply
  4. Set the secret env vars in Render's dashboard: DISCORD_USER_TOKEN, AI_API_KEY, TARGET_USER_ID
  5. Deploy → visit the URL Render gives you

Free Render web services spin down after 15 min of inactivity, killing the bot. Upgrade to $7/mo Starter for 24/7.

Option 3: Run locally (easiest, but only works while your computer is on)
  1. Clone the repo: git clone https://github.com/flexyfresh8-prog/idk.git
  2. Download the .env file using the button above and place it in the project folder
  3. Install & run:
pip install -r requirements.txt
python app.py

Open http://localhost:5000 in your browser → click Start Bot.
